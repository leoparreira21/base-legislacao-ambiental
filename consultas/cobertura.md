# Roteiro de cobertura para consultas

Roteiro editorial, não normativo. Snapshot auditado: `6be0c6224a66797efff147568760f62ac915ae47` (2026-10-05). Inventarie novamente após atualizar a base. As normas abaixo são pontos de entrada; presença não prova vigência externa, aplicabilidade ou completude setorial. IDs entre crases são identificadores do conteúdo, não âncoras HTML do GitHub.

## Consultas locais

```bash
python scripts/consultar.py --inventario
python scripts/consultar.py 'renovacao pgrss' --limite 0
python scripts/consultar.py 'rlo condicionantes' --norma instrucao-normativa-iat-65-2025
python scripts/consultar.py 'mandioca dqo' --limite 0
python scripts/consultar.py '7500-1/00'
python scripts/consultar.py 'normas superiores' --interpretativo --limite 0
python scripts/consultar.py 'pgrss' --historico --limite 0
python scripts/auditar_consultas.py
python -m unittest discover -s testes -v
```

Busca cumulativa por tokens exatos, sem acentos, com normalização do CNAE; não faz stemming, expansão automática, ranking semântico nem decisão jurídica. Varie singular/plural e sinônimos em consultas separadas. `--frase` busca sequência normalizada. `--norma` restringe o arquivo. A ordenação é por arquivo/linha; a primeira página não contém necessariamente os itens mais relevantes. `--offset` pagina; `--limite 0` retorna tudo. O retorno informa total e truncamento.

Artigos preservam incisos e parágrafos no mesmo bloco. Anexos são recuperados por dispositivo com títulos de contexto: leia pais, dispositivos vizinhos e remissões materiais no arquivo. Fórmulas e tabelas mantêm unidades. Modelos apenas nomeados continuam incompletos. `--historico` não resolve vigência por data. `--interpretativo` inclui notas/sínteses/comentários identificados; comentários não viram texto normativo.

O inventário mostra metadados, referências de entrada/saída e pendências. Essas referências incluem textos históricos e editoriais: são pistas de navegação, não relações jurídicas automaticamente confirmadas. URLs são fixadas no commit local e em linhas; se `normas/` tiver mudanças não commitadas, a URL é nula para evitar citar versão diferente.

Os [22 cenários](casos-auditoria.json) são exemplos e regressões curadas, não uma lista exaustiva de atividades nem um classificador automático. O [prompt](prompt-agente.md) exige a leitura e decisão fundamentada do agente.
